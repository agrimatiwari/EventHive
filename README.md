# 🐝 EventHive – Thapar Campus Event Hub

EventHive is a campus event discovery platform for students of Thapar Institute of Engineering & Technology (TIET). It brings campus activities together in one place so students can explore upcoming events, save favourites, and manage registrations.

## ✨ Features

- 🔎 **Explore Events:** Browse featured, popular, and upcoming campus events.
- 🧰 **Search & Filters:** Find events by name, category, date, club, format, and price.
- 📍 **Event Details:** View descriptions, schedules, venues, eligibility, and registration information.
- 📝 **Event Registration:** Register for events and track your registration status.
- 💖 **Saved Events:** Bookmark events and remove them from your saved list.
- 📅 **My Events:** Review your registrations and manage upcoming event plans.
- 🔔 **Notifications:** View simulated event updates and registration reminders.
- 👤 **Student Accounts:** Create a student profile using a Thapar email address.
- 📱 **Responsive Design:** Use the app on desktop, tablet, and mobile screens.
- 🌙 **Theme Toggle:** Switch between light and dark themes.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/agrimatiwari/EventHive.git
```

Navigate to the project folder:

```bash
cd EventHive
```

Open `index.html` in a browser, or use the **Live Server** extension in VS Code to run the application locally. No additional installation is required.

## 💾 Data Storage

EventHive stores demo account details, registrations, saved events, notifications, and theme preferences in browser LocalStorage. This data is available only in the same browser and is not synchronized across devices.

> **Note:** Event data, student verification, registrations, and notifications are simulated for demonstration purposes. They are not connected to TIET or an official campus event system. Organizer tools are not included in this student-focused version.
